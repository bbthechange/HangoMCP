# Hango MCP Server

Model Context Protocol server for the Hango social planning app. TypeScript, ESM, vitest.

## Commands

- `npm run build` — compile TypeScript to `dist/`
- `npm run dev` — run with tsx
- `npm test` — unit tests (vitest)
- `npm run test:e2e` — e2e tests

## Context Directory

The `context/` directory contains documentation for specific parts of the codebase. Read the relevant doc before modifying a feature, and update it when behavior changes.

## Skills Available

- `/code-reviewer` — Review uncommitted changes
- `/wrapup` — End-of-session checklist

## Agents Available

- `code-reviewer` — Detailed code review for architecture compliance
- `privacy-reviewer` — Check for unintentional data collection/sharing
